# 인터뷰와 합의

## 절차
1. 요구사항의 필수 산출물·파일명·형태를 work/STATE.md 에 적는다.
2. 대화의 질문-답변을 work/INTERVIEW.md 표에 원문으로 기록하고 태그를 붙인다: [진술] [확인 필요] [제약] [리스크]
3. 요청자의 원인 가설은 검증 대상(H0)으로 등록한다.
4. harness/templates/AGREEMENT.md 형식으로 합의문 초안과 확인 메시지(5줄 이내)를 쓴다.
5. 확인 답변을 받으면 합의문 상단에 원문을 적는다. 범위가 바뀌면 본문을 고치고 변경 이력에 한 줄 남긴다.

## 질문 체크리스트
- 공통: 지표·용어 정의, 범위, 이미 확인한 것, 제약(기한·자원), 산출물(대상·형식·반복 사용·화면 필요)
- 숨은 조건: 지금 어떤 불만·예외가 생기나, 언제 이용을 포기하나, 특정 시점·대상에 몰리나, 극단적인 경우는 어떻게 하나, 꼭 지켜야 하나 아니면 좋으면 좋은가
- 제조·공정 작업일 때: 설비(PM·부품·레시피), 자재, 방법(조건·배정), 측정(프로그램·장비·판정 기준), 다른 제품·라인

## 답이 애매할 때
기본안을 제안하고 확인을 받는다. 확인을 받으면 [진술], 못 받으면 [가정]으로 합의문 조건 표에 적는다.
